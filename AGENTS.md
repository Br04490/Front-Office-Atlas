# Crystal design guardrails

The local git tag `CRYSTAL_DESIGN_V1` is the approved-style design baseline awaiting user review.

- Keep the bright white and ice-blue Crystal visual identity, translucent glass panels, top navigation, and permanent left sidebar.
- Preserve all 30 franchise records, distinct local marks, directory search and filters, team selector, and six team tabs when extending the site.
- Keep Houston as the default franchise and preserve a selected franchise while changing tabs.
- Treat roster, game, possession, statistical, and coaching content as unverified until sourced. Do not invent NBA results or player identities.
- Make a local recoverable git commit before major changes. Do not push to GitHub until the user explicitly approves.
- Wait for visual approval before implementing the four-player Houston photo and flip-card prototype, and wait for card approval before all-team roster ingestion.
