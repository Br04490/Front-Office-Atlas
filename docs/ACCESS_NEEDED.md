# Access needed for Phase 1

| Provider | Site | Data | Exact access gap | Dependent Atlas features |
|---|---|---|---|---|
| NCAA school athletics sites via ncaapyscraper | [Project](https://github.com/fakhar-ud-din/ncaapyscraper) | Current rosters, coaches, photos | The project's MIT code license does not establish rights to redistribute each school's content or images. Need source-specific permission or a licensed feed for public Atlas use. No published uniform subscription price established. | D1 roster and coach publication, athlete portraits |
| SportsDataverse / original statistics providers | [hoopR](https://github.com/sportsdataverse/hoopR) | NCAA games and player statistics | Need to verify each underlying dataset's publication rights, season availability, and ID mapping. Some named providers require accounts or subscriptions; no blanket cost applies. | NCAA stats, trends, shot and game views |
| NBA G League / NBA Stats | [Official stats FAQ](https://stats.gleague.nba.com/help/faq/) and [NBA Terms of Use](https://www.nba.com/termsofuse) | G League teams, rosters, photos and stats | Official FAQ says stats are not available for download; NBA terms require express prior consent for a comprehensive, regularly updated stats database. Need an NBA/G League data license or written permission covering Atlas use. No public price verified. The tested 2026–27 player endpoint currently has zero rows. | G League directory, rosters, photos, profiles and statistics |

Credentials or licensing evidence should be supplied through a secure channel, never committed into this repository. The data model and local validation can continue while access is resolved.
