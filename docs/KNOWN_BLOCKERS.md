# Known blockers — 2026-11-18

- **NBA contracts:** `atlas_contract_years` has 0 records. The authorized CSV importer exists, but no licensed current contract file or rights manifest has been supplied. Publicly viewable Spotrac data is not assumed reusable. No salary figures are fabricated.
- **Team cap accounting:** Complete team salary requires reconciled player cap hits, dead money, holds, incomplete roster charges and a team-season attestation. A visual removal is not an official waiver or cap-room calculation.
- **Game-level analytics:** 0 player game logs, 0 shot events and 0 possessions in the local warehouse. Player Trends, shot maps and on/off require those inputs.
- **Non-NBA pools:** A rights-gated identity importer now exists, but no authorized current D1, high school ranking, EuroLeague or G League file has been imported. Their player counts remain zero rather than demo filler. Statistics and cross-league identity matching need separate validated imports.
- **Phase 1 source access:** ncaapyscraper, hoopR and nba_api code licenses do not establish Atlas rights to republish the underlying school/NBA data or portraits. See [ACCESS_NEEDED.md](ACCESS_NEEDED.md). Official school-by-school verification and complete current rosters are not yet available in the local warehouse.
- **Official G League directory:** The [official teams page](https://gleague.nba.com/teams) lists the current clubs and the [league FAQ](https://gleague.nba.com/faq) says 31 teams are expected in 2026–27, but the site states that its content may not be duplicated or redistributed. Bulk roster import and image reuse need a permitted feed or license; Atlas has not copied that directory into its database.
- **Media:** 521 NBA image URLs were found, but uniform verification and publication rights are separate checks. No other-league photo rights have been established.
- **Operational releases:** Approval workflows and internal transaction documents must remain private and clearly unofficial. Provider credentials and protected team data need server-side authentication and team isolation before external use.
- **Transaction review:** The local case queue is in memory and supports draft and needs-review checks only. Durable team-isolated approval records, authenticated decision makers, CBA rule verification and external confirmation are still required.
- **Build gate:** This repository has JavaScript tests but no `build` or TypeScript script. That absence is reported rather than represented as a passing build.
