# Known blockers — 2026-11-18

- **NBA contracts:** `atlas_contract_years` has 0 records. The authorized CSV importer exists, but no licensed current contract file or rights manifest has been supplied. Publicly viewable Spotrac data is not assumed reusable. No salary figures are fabricated.
- **Team cap accounting:** Complete team salary requires reconciled player cap hits, dead money, holds, incomplete roster charges and a team-season attestation. A visual removal is not an official waiver or cap-room calculation.
- **Game-level analytics:** 0 player game logs, 0 shot events and 0 possessions in the local warehouse. Player Trends, shot maps and on/off require those inputs.
- **Non-NBA pools:** Duke's official roster remains the only school-certified complete roster. A local SportsDataverse snapshot supplies 365 Division I groups, 5,585 provider-listed player IDs and 179,312 numeric season fields; official roster reconciliation and ESPN-origin public reuse rights remain pending. User files supply 150 boys and 50 overseas men as unverified selections. Current G League rosters remain absent.
- **Phase 1 source access:** ncaapyscraper, hoopR and nba_api code licenses do not establish Atlas rights to republish the underlying school/NBA data or portraits. See [ACCESS_NEEDED.md](ACCESS_NEEDED.md). The SportsDataverse producer labels its data CC BY 4.0, but ESPN-origin commercial/public reuse still requires a separate rights determination. The raw snapshot and exports remain local-only. Duke factual roster fields are sourced from its official site; broader school-by-school verification remains pending.
- **D1 directory completeness:** The pinned ncaapyscraper multi-sport school catalog has 356 Division I candidates, not a reconciled current men's basketball program list. No school is counted as imported from that catalog. See [PHASE1_SOURCE_REVIEW.md](PHASE1_SOURCE_REVIEW.md).
- **Official G League directory:** The [official teams page](https://gleague.nba.com/teams) lists the current clubs and the [league FAQ](https://gleague.nba.com/faq) says 31 teams are expected in 2026–27, but the site states that its content may not be duplicated or redistributed. Bulk roster import and image reuse need a permitted feed or license; Atlas has not copied that directory into its database.
- **Official G League statistics:** The [stats FAQ](https://stats.gleague.nba.com/help/faq/) says stats are not available for download, and [NBA Terms of Use](https://www.nba.com/termsofuse) require express consent for a comprehensive, regularly updated G League stats database. A read-only endpoint smoke check returned zero 2026–27 player rows; no rows were imported.
- **Media:** Image bytes load for 521 NBA, 5,259 NCAA and 149 grassroots records, but visual identity, current uniform and publication rights are separate checks. Four NBA, 326 NCAA and one grassroots record lack a URL. All 50 overseas candidates returned HTTP 429 and remain unverified. No new non-NBA photo has been approved for display.
- **Operational releases:** Approval workflows and internal transaction documents must remain private and clearly unofficial. Provider credentials and protected team data need server-side authentication and team isolation before external use.
- **Transaction review:** The local case queue is in memory and supports draft and needs-review checks only. Durable team-isolated approval records, authenticated decision makers, CBA rule verification and external confirmation are still required.
- **Build gate:** This repository has JavaScript tests but no `build` or TypeScript script. That absence is reported rather than represented as a passing build.
